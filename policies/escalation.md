# Escalation SOP

1. If customer sentiment drops below `handoff_sentiment_below`, any `handoff_keywords` appear, or the customer asks for a person, a human must own the case.
2. Before handing off, do everything safe that helps (e.g. start the reversal) so the human starts ahead.
3. Every hand-off carries a brief: what happened, what Dost already did, recommended next step.
